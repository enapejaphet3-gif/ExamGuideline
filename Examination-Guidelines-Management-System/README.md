## 1. Project Description

ExamGuide is a responsive web-based application designed
to help students access and understand examination
instructions, rules, regulations, and guidelines.

The application provides a centralized interface where
students can view examination guidelines, read instructions,
search for specific rules, and access examination announcements.

It also provides basic content management features that allow
users to add, edit, and delete examination guidelines.

ExamGuide was developed using HTML, CSS, and JavaScript.

Browser Local Storage is used to save guidelines,
announcements, acknowledgement records, and theme preferences.

The application does not require a backend server or database.

---

## 2. Problem Statement

Examination instructions and guidelines are important
for ensuring that students understand examination
procedures and regulations.

However, examination information may be distributed
through different communication channels, making it
inconvenient for students to locate specific instructions.

Students may also overlook important guidelines when
information is not properly organized.

ExamGuide addresses this problem by providing a simple
web-based platform where examination instructions,
guidelines, and sample announcements are organized
and accessible from one interface.

---

## 3. Aim of the Project

The aim of this project is to develop a web-based
Examination Instructions and Guidelines Management System
that enables students to access, search, and understand
examination information conveniently.

---

## 4. Objectives of the Project

The objectives of the application are:

1. To design a responsive examination guidelines platform.
2. To provide a centralized interface for examination rules.
3. To organize examination guidelines into categories.
4. To allow users to search and filter examination guidelines.
5. To display instructions for different examination stages.
6. To provide a section for examination announcements.
7. To allow guidelines to be added, edited, and deleted.
8. To allow users to acknowledge guidelines they have read.
9. To save application data using browser Local Storage.
10. To provide a user-friendly interface for mobile
    and desktop devices.

## 10. How to Use ExamGuide

### Viewing Guidelines

1. Open the application.
2. Click Guidelines in the sidebar.
3. Browse the available examination guidelines.
4. Select a category to filter guidelines.
5. Use the search field to find specific information.

### Acknowledging Guidelines

1. Open the Guidelines section.
2. Find a guideline.
3. Click Mark as Read.
4. The dashboard will update the acknowledgement count.

### Adding Guidelines

1. Click Add Guideline.
2. Enter the guideline title.
3. Select a category.
4. Enter the guideline description.
5. Click Save Guideline.

### Editing Guidelines

1. Open the Guidelines section.
2. Find the guideline to update.
3. Click Edit.
4. Modify the required information.
5. Click Save Guideline.

### Deleting Guidelines

1. Open the Guidelines section.
2. Find the guideline to remove.
3. Click Delete.
4. Confirm the deletion.

### Viewing Examination Instructions

1. Click Instructions.
2. Read the instructions organized into three stages:
   before, during, and after examinations.

### Adding Announcements

1. Click Announcements.
2. Click Add Announcement.
3. Enter the announcement title and message.
4. Select the announcement priority.
5. Click Publish Announcement.

### Switching Themes

1. Click Dark Mode to enable the dark theme.
2. Click Light Mode to restore the original theme.

## 11. Guideline Categories

The system organizes guidelines into five categories:

1. General Rules
2. Exam Conduct
3. Allowed Materials
4. Exam Malpractice

---

## 12. Data Storage

ExamGuide uses browser Local Storage.

The following storage keys are used:

- examguide_guidelines
- examguide_announcements
- examguide_acknowledgements
- examguide_theme

Saved information remains available after refreshing
the browser unless the browser's stored website data
is cleared.

Data is not automatically synchronized between devices.

---

## 13. Project Limitations

1. The application does not have user registration or login.
2. It does not provide authenticated administrator access.
3. Information is stored locally in each browser.
4. Changes made on one device do not appear on other devices.
5. The application does not connect to an official
   institutional examination database.
6. The application does not send notifications.
7. Sample guidelines and announcements are not official
   institutional examination policies.
